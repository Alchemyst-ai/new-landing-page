# This is a Draft Post

This blog post is marked as `draft: true` in the frontmatter, so it won't appear in the blog listing.

## Features Demonstrated

1. **Git Integration**: Last modified dates are automatically tracked
2. **Draft System**: Posts marked as draft are filtered out
3. **Read Time Calculation**: Automatic reading time estimation

To publish this post, simply change `draft: true` to `draft: false` in the frontmatter.

## Testing the System

You can test the system by:

- Setting `draft: false` to make this post visible
- Checking the read time calculation
- Viewing the last modified date from Git history

This content is long enough to demonstrate the read time calculation feature working properly with a realistic word count.
